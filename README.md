# 音频字幕

Created by haodongsheng

macOS 菜单栏原型：通过 Core Audio Process Tap 捕获系统音频，再使用系统语音识别生成中文字幕。需要 macOS 14.2 或更新版本，以及 Xcode 命令行工具。

## 构建与使用

```bash
./scripts/build.sh
open "build/音频字幕.app"
```

点击菜单栏的「字幕」，在「音频来源」中选择「全部来源（混合）」或一个当前正在输出的进程，再选择「开始监听」。首次使用时请按系统提示授予语音识别和系统音频录制权限。如果曾拒绝权限，请在系统设置的「隐私与安全性」中重新开启，再重启应用。

选择单个进程前请先让它播放音频，然后重新打开菜单刷新列表。应用可能通过辅助进程输出，因此列表显示的是进程名和 PID，未必是主应用名称。停止监听后可以更换来源；进程退出或重启后需要重新选择。

多个来源同时播放时，全部来源模式会把声音混合后识别，无法可靠地分别标注来源，声音重叠也可能影响识别效果。如只需要某个来源，选择其对应进程。

菜单栏实时显示当前字幕的末尾；点击可查看当前和上一段，也可打开「查看字幕历史」查看本次识别结果。应用根据系统识别出的标点及词语间较长的停顿分段，识别过程中的文字仍可能被系统修正。当前版本默认识别中文，尚不支持切换语言或保存字幕。音频捕获和识别分别运行在独立队列，界面在主线程更新。识别会分段重启，切换期间最多暂存五秒音频；缓冲超限时菜单会显示丢弃时长，仍可能出现漏字。菜单中的音频状态可帮助判断是否收到了声音；收到声音并不代表其中一定有可识别的语音。字幕延迟取决于系统语音识别和音频内容，无法保证零延迟。系统语音识别的网络使用情况取决于设备、语言和系统配置；本原型不强制离线识别。受保护内容可能无法捕获。
