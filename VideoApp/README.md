# 视频翻译字幕（macOS 原型）

Created by haodongsheng

## 构建与使用

需要 Apple Silicon Mac、macOS 15 或更新版本。构建还需要 Xcode 命令行工具和 CMake。

```bash
# 首次构建或清理 build 后，联网准备依赖：
./scripts/prepare-video-deps.sh
./scripts/build-video.sh
open "build/视频翻译字幕.app"
```

1. 将本地视频拖到应用窗口，或点击「打开视频」选择文件。常见兼容组合为 MP4 / MOV、H.264 / HEVC 视频和 AAC 音频，实际支持情况取决于 macOS 和文件编码。
2. 选择音轨和原文语言（英语、日语、汉语普通话、韩语或泰语）。汉语直接生成中文字幕，其他语言翻译成中文；具体语言组合是否可用取决于系统及已安装模型。当前音轨以编号显示，可能需要试听或尝试不同音轨。
3. 点击「生成字幕」，多语言 base 模型、FFmpeg 和 whisper-cli 均已内置，无需单独安装或下载。点击「识别模型」可以选择其他 whisper.cpp 兼容的本地多语言模型，或切回内置 base。非中文视频仍需按系统提示准备 Apple 翻译语言包。
4. 生成过程中可播放视频，字幕只会出现在已经处理完成的片段。建议等待处理超过当前播放位置再观看。

字幕生成按 20 秒分段，译文和原文显示在播放器中。点击「字幕设置」可展开或收起播放器右侧面板；面板默认收起，支持手动开启示例字幕预览、调整字体、字号、颜色、文字及背景不透明度、水平和垂直位置，也可以隐藏原文或恢复默认值。字幕样式设置会保留。处理速度取决于系统识别和翻译服务；字幕边界可能截断句子，内容也可能出现识别或翻译错误。处理完成的字幕会保存在 macOS 用户缓存目录；重新打开同一路径且文件未修改的视频时，会按音轨和原文语言自动加载缓存。点击「生成字幕」会先删除当前配置的缓存，再重新识别；取消或失败不会保存未完成结果。移动、修改或替换视频后可能无法命中旧缓存。选择其他视频会取消当前任务。

当前版本使用 AVFoundation 播放和提取音轨，因此只支持本机系统能够解码的文件；尚未集成 FFmpeg，也尚不支持读取原有字幕轨、导出字幕、跨平台构建或受保护的视频。Whisper 在设备本地识别音频；Apple Translation 在设备上翻译文字。

## 本地识别依赖

App 内置 Apple Silicon 版 FFmpeg、whisper-cli 和 base 多语言模型；也可手动选择兼容 whisper.cpp 的 GGML 多语言模型，所选路径会保留，不同模型分别缓存字幕。模型约 142 MiB，App 总体积约 187 MiB；删除 App 会一并删除内置模型。

FFmpeg 每次只提取 20 秒为 16 kHz 单声道 WAV，临时音频及识别结果在处理后删除。视频播放与导入仍由 AVFoundation 处理，不等于支持所有 FFmpeg 视频格式。本地识别不需要语音识别云服务；非中文语音的中文翻译仍需要 Apple Translation 的语言资源。

此版本仅用于本机测试。FFmpeg 来源为 eugeneware/ffmpeg-static b6.1.1 构建，whisper.cpp 版本为 v1.7.6；相关许可证随 App 附带，分发前需单独核实许可及签名要求。
